# Apply to Grafana

Run `${CLAUDE_SKILL_DIR}/scripts/apply.sh` with the arguments given, exactly as passed:

```bash
bash "${CLAUDE_SKILL_DIR}/scripts/apply.sh" $ARGUMENTS
```

## Before running

If `--apply` is present in `$ARGUMENTS`, stop and show the user:
- Which files will be applied, and a one-line summary of each (from a quick `Read`, not from re-parsing).
- That this writes to a real Grafana instance (dashboards via `/api/dashboards/db`, alert rules via the provisioning rule-groups API) and is not trivially reversible.
- Ask for explicit confirmation before running the `--apply` command. Never add `--apply` yourself if the user only asked to "check" or "preview" — that's the dry-run default, run it without the flag.

## After running

Show the script's output as-is. If it exited non-zero, do not retry automatically — report the failure (validation error, missing env var, HTTP failure) and let the user decide.

## Rules

- Never invent a file path — only apply files that exist and that the user pointed at (typically the output of `/obs-panel` or `/obs-alert`).
- The script requires `GRAFANA_ADMIN_TOKEN`, a token distinct from `GRAFANA_SERVICE_ACCOUNT_TOKEN` (which the read-only agents use). If it's unset, surface the script's error rather than trying to work around it.
